RL3D

전 세계 로켓 발사를 지도에 표시하고 위성을 실시간으로 움직이는 Windows 데스크톱 앱. 통과 예측·지상궤적·낮밤 터미네이터까지 직접 계산한다.

Python · pywebview · MapLibre GL · PyInstaller

저장소 개발 노트 2편 노트 후보 목록 다섯 프로젝트 색인

무엇을 하는가

발사 정보는 Launch Library 2, 위성 궤도는 Celestrak TLE 에서 받는다. 위성 위치는 satellite.js 의 SGP4 로 매 초 계산해 지도에 찍는다.

관측 위치를 지도에서 찍으면 향후 24시간의 통과를 시각·방위·최대고도까지 낸다 — 외부 API 없이 직접 계산한다.

API 한도가 시간당 약 15회라 캐싱이 설계의 출발점이다. 발사 15분 · TLE 2시간 TTL 로 시간당 약 8요청에 맞춘다. 실패하면 오래된 캐시라도 반환해 화면이 비지 않게 한다.

  • 위성 추적SGP4 실시간 · 그룹 선택 · 궤도 대역 필터 · 지상궤적

  • 낮/밤 터미네이터태양 위치로 야간 반구 음영
  • 오프라인 대응번들 라이브러리 + 캐시 · 타일만 온라인

화면

개발 노트

화면 대부분이 지도라, 틀리는 방식도 «아무것도 안 보인다» 쪽으로 몰렸다. 기능 소개가 아니라 판단 기록이라 «이건 아직 안 쟀다» 도 그대로 적는다.

  1. 01고장이 아닌데 고장으로 보였다상태 전달 — 정상 동작의 조합이 빈 화면을 만드는 일곱 가지 경로
  2. 02공허하게 통과한 검사들검증 — 골든을 만들 수 없는 계산을 물리 불변식으로 재는 법
노트 본문은 저장소에 있다 — 이 페이지는 링크만 건다. 다른 프로젝트의 기록은 개발 노트 색인에.
